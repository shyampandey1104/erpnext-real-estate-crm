# 🏢 ERPNext Real Estate CRM & Property Lease Manager

[![Python 3.9+](https://img.shields.io/badge/python-3.9+-blue.svg)](https://www.python.org/downloads/)
[![ERPNext](https://img.shields.io/badge/ERPNext-Real%20Estate-blue.svg)](https://erpnext.com)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

An enterprise **Real Estate CRM and Property Management System** for **ERPNext**. Automates unit availability across residential/commercial towers, manages buyer booking tokens, structures tenant lease contracts, and generates automated monthly rent demand invoices.

---

## ⚡ Highlights
- 🏙️ **Unit Inventory**: Carpet area, floor layouts, dynamic pricing, and booking lockouts.
- 📝 **Tenant Lease Contracts**: Rent schedules, security deposit holding, and auto-invoicing.
- 🧪 **Pytest Suite**: Complete unit tests included.
